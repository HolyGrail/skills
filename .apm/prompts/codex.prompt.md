## Codex

Codex (OpenAI の codex CLI) に `codex exec` でコード生成を委任します。使用モデルは `~/.codex/config.toml` の `model` 設定に従います。

### 使い方

`/codex` の後に実装したい内容を書いてください。

要件が明確で自己完結した生成単位（関数・クラス・モジュール、ボイラープレート、ユニットテスト、言語間変換、設定ファイル）に向きます。既存アーキテクチャの理解が前提の改修、複数ファイルにまたがるリファクタリング、分析・レビュー・デバッグには向きません。

### 実行手順

1. プロジェクト構造・関連ファイル・型定義を確認し、Codex に渡す文脈を固める
2. 英語で自己完結したプロンプトを組み、Bash で `codex exec -C <作業ディレクトリ> -s workspace-write` を呼ぶ。呼び出し方は CLAUDE.md「Codex CLI」節に従う（`model` は指定しない）
3. `git diff` で生成コードをレビューし、プロジェクト規約に合わせて調整してからユーザーに提示する
